Flex-EMG Acquisition System

A wearable surface-electromyography (sEMG) platform that reads muscle activity from the forearm, cleans it with a real-time digital filter chain, and classifies hand gestures using a lightweight machine-learning model. It spans the full stack: a custom analog front-end PCB, ESP32 firmware that streams ADC samples over WiFi, and a Python backend that filters the signal, recognizes gestures, and broadcasts results over WebSocket.

How it works

Microvolt-level EMG signals from surface electrodes are conditioned by a custom analog front-end, digitized by a 24-bit ADC, streamed off the ESP32, filtered in real time, and classified into gestures — then fanned out live to any client over WebSocket.

Hardware — the analog front-end

The custom AFE board conditions a microvolt-level EMG signal into a clean digital stream. The KiCad source — schematic, layout, footprints, and BOM — lives in the repository, and the board was assembled in-house on a reflow + rework bench with placement checked under a microscope.

  • ADS1220 — 24-bit delta-sigma ADC with integrated PGA
  • OPA4322 — quad precision op-amps for the analog filter / gain stages
  • MCP4141 — digital potentiometer for programmable gain
  • ESP32-C3 — onboard wireless MCU for sampling and streaming

Software — signal processing & ML

The Python backend is a modular real-time pipeline. A single config module is the source of truth for sample rate, filter, and connection settings; the signal processor applies a bandpass (20–500 Hz) plus a 60 Hz notch filter chain using SciPy SOS; the ESP32 client reads over WiFi/serial with auto-reconnect; and the classifier turns the cleaned signal into gestures.

  • Real-time filtering — 20–500 Hz bandpass + 60 Hz notch (SciPy second-order sections).
  • Gesture classification — Hudgins time-domain features feeding a StandardScaler + LDA pipeline.
  • WebSocket server — fans processed frames out to all connected clients.
  • Hardware-free simulator — a live viewer and training UI so the full pipeline can be developed and demoed without a board attached.
