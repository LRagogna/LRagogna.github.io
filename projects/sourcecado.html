Overview

Sourcecado runs recruiting sourcing end-to-end as a local-first desktop app, so sensitive candidate data never leaves the user's machine. It finds candidates, drafts tailored outreach, and keeps a clean, hand-off-ready file on everyone it touches. The principle throughout is trust: the agent proposes, a human approves, and every step is logged and reviewable.

What it does

01

Finds candidates

Searches and enriches candidate profiles, assembling structured, hand-off-ready person files a recruiter can act on immediately.

02

Drafts outreach

Writes tailored outreach per candidate, held behind an approval gate so nothing is sent without a human in the loop.

03

Connects the stack

MCP/OAuth connectors to Gmail, Drive, Calendar, and Apollo let the agent read context and act across real tools.

04

Stays auditable

An auditable run ledger records every tool call, with secret redaction that keeps PII and credentials out of logs.

05

Runs locally

A Rust/Tauri macOS shell wraps the React frontend and Python backend into a single local-first desktop app.

06

Ships safely

1,600+ tests and a 3-stage CI pipeline gate every release, ending in signed, notarized builds with auto-update.

The agent loop

Sourcecado runs an LLM tool-calling loop: the model plans, calls a tool, observes the result, and repeats — but outbound actions pause at an approval gate, and the whole run is written to a ledger as it goes.
