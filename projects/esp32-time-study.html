Portable ESP32 Time-Study System

An end-to-end engineering project that turns production instructions into portable, operator-controlled time studies. The system combines a battery-powered ESP32 terminal, custom electronics and enclosure design, embedded firmware, and a Windows desktop application for creating, recording, reviewing, and exporting study data.

Engineering outcome

This project replaced a centralized, manually coordinated timing process with a portable workflow that can be used directly at the workstation. A single system now supports the full path from study creation to recorded results — integrating mechanical design, electronics, embedded programming, desktop software, serial communication, and structured data export into one deployable tool.

Key accomplishments

  • Designed and built a portable ESP32 operator terminal for decentralized time collection.
  • Developed a custom 3D-printed enclosure in SolidWorks around the display, controls, battery system, and internal electronics.
  • Created a three-button interface that lets operators select studies, move between steps, and start/stop timing without a keyboard.
  • Implemented local CSV storage so studies remain available directly on the ESP32.
  • Defined a lightweight serial command protocol between the Windows application and the embedded device.
  • Built a desktop application for study creation, file management, CSV preview, deletion, and Excel export.
  • Added editable step previews so users can correct, reorder, remove, or add operations before transferring a study.
  • Developed the system for use across multiple manufacturing departments, demonstrating the design could scale beyond a single workstation.

Hardware

The custom AFE packages the ESP32, display, physical controls, battery hardware, and interface electronics into a portable 3D-printed enclosure. A custom interface PCB organizes the ESP32 headers, display and control connections, power components, and enclosure mounting points; the 3D board view was used to review component placement and mechanical integration before assembly.

  • ESP32-D DevKit development board
  • 3.2-inch display with three momentary pushbuttons and an on/off power switch
  • Dual-18650 battery holder and charging board with 2.5 mm JST-EH connectors
  • Custom interface PCB and a SolidWorks-designed 3D-printed enclosure

Software

ESP32 firmware

The firmware provides the on-device workflow and file-management layer: it displays stored studies and step information, uses physical buttons for menu navigation and timing control, accumulates elapsed time for each operation, stores study definitions and results as CSV files, and responds to commands from the desktop application over a 115200-baud serial connection.

Windows Study Manager

The desktop application is written in Python and uses a local HTML/CSS/JavaScript interface through pywebview. It provides four main workflows: a Home screen that detects the connected ESP32 and shows device status; Create Study, which parses a study document, previews its steps, and uploads the final study; Current Studies, which lists stored CSV files and previews recorded results; and Export, which combines selected studies into an Excel workbook with one worksheet per study.

Results use a straightforward CSV structure — step number, description, and time (mm:ss) — keeping the device implementation lightweight while making the data easy to inspect, archive, and analyze.
