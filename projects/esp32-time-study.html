Portable ESP32 Time-Study System

An end-to-end system that turns production instructions into portable, operator-controlled time studies — a battery-powered ESP32 terminal with custom electronics, enclosure, and firmware, plus a Windows app to create, record, review, and export study data.

Key accomplishments

  • Designed and built a portable ESP32 operator terminal for decentralized time collection.
  • Developed a custom 3D-printed enclosure in SolidWorks around the display, controls, battery system, and internal electronics.
  • Created a three-button interface that lets operators select studies, move between steps, and start/stop timing without a keyboard.
  • Implemented local CSV storage so studies remain available directly on the ESP32.
  • Defined a lightweight serial command protocol between the Windows application and the embedded device.
  • Built a desktop application for study creation, file management, CSV preview, deletion, and Excel export.
  • Added editable step previews so users can correct, reorder, remove, or add operations before transferring a study.
  • Developed the system for use across multiple manufacturing departments, demonstrating the design could scale beyond a single workstation.

Hardware

The device packages the ESP32, display, controls, battery, and interface electronics into a portable 3D-printed enclosure. A custom interface PCB organizes the ESP32 headers, display and control connections, power components, and mounting points; the 3D board view checked placement and mechanical fit before assembly.

  • ESP32-D DevKit development board
  • 3.2-inch display with three momentary pushbuttons and an on/off power switch
  • Dual-18650 battery holder and charging board with 2.5 mm JST-EH connectors
  • Custom interface PCB and a SolidWorks-designed 3D-printed enclosure

Software

ESP32 firmware

The firmware runs the on-device workflow and file management: it shows stored studies and steps, uses physical buttons for navigation and timing, accumulates elapsed time per operation, stores definitions and results as CSV, and answers the desktop app over a 115200-baud serial link.

Windows Study Manager

A Python desktop app with a local HTML/CSS/JS interface via pywebview, with four workflows: Home detects the connected ESP32 and shows status; Create Study parses a study document, previews steps, and uploads; Current Studies lists stored CSVs and previews results; and Export combines studies into an Excel workbook, one worksheet each.

Results use a simple CSV structure — step number, description, time (mm:ss) — keeping the device lightweight and the data easy to inspect, archive, and analyze.
